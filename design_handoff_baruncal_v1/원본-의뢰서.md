## ⚠ 먼저 — 이 프로젝트의 현재 상태

**코드베이스가 없다.** 리포지토리 생성 전이며 화면은 한 장도 구현돼 있지 않다.
**전량 신규 와이어프레임**이고 리디자인 대상은 0개다.

| 표기 | 의미 | 디자이너 재량 |
|---|---|---|
| **✅ v1.0 확정** | 기능·정보구조(IA)·표시 규칙이 **결정 완료**(C-1~C-52) | **비주얼은 전면 재량.** 단 §3 공통 규칙과 각 화면의 「표시 규칙」은 변경 불가 |

> **⚠ 결정 레지스트리 C-1~C-52가 최상위 권한이다.** 이 문서 본문과 충돌하면 레지스트리가 이긴다.

## 0. 제품 컨텍스트

### A. 앱

**바른달력** — **"틀리지 않는 한국 달력"**

```
❌ 만들지 않는 것:  "음력이 보이는 달력"    (삼성·네이버가 이미 함 / 402만 앱이 이미 함)
❌ 만들지 않는 것:  "큰 글씨 달력"          (3개 앱이 시도해서 전멸)
❌ 만들지 않는 것:  "제사 앱"               (제사의달인 50만+, 리뷰율 0.19% = 한 번 열고 버림)
❌ 만들지 않는 것:  "만세력·사주 앱"        (점신 500만+ 점령)

✅ 만드는 것:  24절기·삼복·한식·대체공휴일·윤달·간지 절입을 국가 확정 데이터로 맞추고,
              "왜 이 날짜인지"를 화면에서 증명하는 달력
```

- **스토어 한 줄**: *"초복 날짜, 이 앱은 틀리지 않습니다."*
- **부제**: *"한국천문연구원 기준 음력·24절기·공휴일 — 매년 자동으로 맞춥니다"*

### B. 이 앱이 존재하는 이유 — 디자인의 출발점

경쟁 앱 저평점 **674건**을 전수 분류한 결과, 최다 단일 사유가 **「날짜가 틀린다」**(Play 51건 / iOS 24건+)였다. 그리고 **그 오류의 비용이 사회적이다.**

> *"치킨값 물어내세요"* (말복 오류)
> *"시아버님이랑 말복 날짜로 실랑이했어요"*
> *"이 달력 보고 일정 예약했다가 **호텔 숙박비 하루 날렸음**"* (입춘 오류)
> *"어머니 제사가 음력 10월 7일인데 … **9월이 29일까지밖에 없네요**"*
> *"24년 2월 5일이 갑진년이라니 못 믿겠다"*

**사용자는 이 앱을 믿고 돈과 체면을 건다.**

> **디자인 함의**: 이 앱의 경쟁 우위는 예쁨이 아니라 **신뢰**다.
> 그래서 **「왜 이 날짜인가요?」 근거 화면(S3)이 이 앱의 심장**이다. 다른 달력에는 없다.
> 화려함보다 **정확성이 보이는 것 · 가독성 · 오탐 없는 표시**가 우선한다.

### C. 타겟 유저

| 층 | 여는 이유 | 설계 함의 |
|---|---|---|
| **A. 40~70대 실사용자** (최다) | 제사·생신·초복·손없는날 확인 | **큰 글씨 · 단순 계층 · 오탐 없는 표시가 기본값** |
| B. 30~50대 실무자 | 음력 생일 챙기기, 일정 관리 | 반복 일정 · 다단 알림 |
| C. 간지·절기 관심층 | 사주·택일 참고 | 근거 화면 · 토글로 숨김 가능 |

- **사용 빈도**: 주 1~3회 + **명절·복날·제사 전후 급증**. 위젯으로 완결되는 경우가 많다.
- **디지털 숙련도**: 낮다. `minSdk 23`은 **효도폰 실측 근거**다.

### D. 이 앱의 "시각적 주인공"

**화면에 따라 둘이다.**

1. **달력 셀의 양력 날짜 숫자** (홈) — 가장 크고 진하다. 그 아래 **음력이 작게** 붙는다.
2. **근거 화면의 계산 과정** (S3) — *"하지 2026-06-21(庚일) → ① 06-21 ② 07-05 ③ 07-15"*.
   **이걸 얼마나 읽기 쉽게 보여주느냐가 이 앱의 차별점 그 자체다.**

부(副)주인공: **오늘 표시**(굵은 테두리 + 배경), **공휴일 빨강**, **백업 상태 배지**.

### E. 플랫폼·제약

| 항목 | 값 |
|---|---|
| 플랫폼 | **Android 우선** (Flutter, 공수장부와 동일 계열) |
| 방향 | **가로/세로 자유 회전 + 태블릿 2단 레이아웃** (C-46) — **회전 잠금 금지**(실측 결함 3건) |
| 기준 뷰포트 | 세로 **360 × 800 dp**. 최소 대응 **320 dp** |
| 테마 | **시스템 · 라이트 · 다크** 3택 |
| 언어 | 한국어 단일 |
| 네트워크 | **완전 오프라인 동작.** 로그인·서버 없음 |
| 최소 SDK | **23** (효도폰) |
| 글자 크기 | **앱 자체 배율 3단계(1.0 / 1.25 / 1.5) × 시스템 배율, 총 2.6에서 clamp** (C-44) |

### F. 수익 모델

- **v1.0: 무료 + 배너 광고 1지면(홈 하단만) + 평생권 ₩7,900.**
- **페이월 화면이 v1.0에 있다.** (공수장부와 다르다 — 거긴 v1.1이었다)

| 무료 (C-47) | 평생권 ₩7,900 (C-48) |
|---|---|
| 달력 · 음력 · 절기 · 잡절 · 간지 · 공휴일 · 손없는날 | 광고 제거 |
| **변환기 · 검색 · 위젯 · 백업** | 큰글씨 3단계 |
| **기일·생신 무제한** | 다단 사전 알림 |
| | 다크모드 · 위젯 테마 |

> **정확성과 데이터를 인질로 잡지 않는다. 그게 소구점이다.**
> **검색은 영구 무료다** — iOS 1위가 검색을 사후 유료화해서 욕먹은 자리다(C-48 대조군).

## 1. 전체 유저 플로우

### 1-A. 첫 실행

```
   [설치 · 실행]
        │
        ▼
   ┌──────────────────────────────────────┐
   │  스플래시 (최대 1.0초)                 │  ← 광고 없음
   └──────────────────────────────────────┘
        │
        ▼
   ┌──────────────────────────────────────┐
   │  S1 홈 · 월 달력 (오늘)                │  ← 온보딩 없음. 바로 달력
   │                                        │
   │  하단 1줄 (C-49 사전 고지):             │
   │  "모든 달력 기능 무료 · 구독 없음 ·      │
   │   광고 제거는 1회 결제 ₩7,900"          │
   └──────────────────────────────────────┘
```

> **온보딩 화면을 만들지 않는다.** 달력은 열면 바로 이해되는 물건이다.
> 대신 **첫 화면 하단에 페이월 사전 고지 1줄**이 들어간다(C-49) — 나중에 뒤통수 맞았다는 인상을 원천 차단한다.

### 1-B. 일상 플로우 (주 1~3회 · 전체의 80%)

```
   [위젯 확인]  ──▶  (대개 여기서 끝난다)
        │
        │ 자세히 보려면
        ▼
   S1 홈 · 월 달력  ──[날짜 탭]──▶  S2 날짜 상세 시트
        │                              │
        │ ◀── 좌우 스와이프 = 월 이동    ├─ 음력 · 간지 · 손없는날
        │                              ├─ 특일 · 일정 목록
        │                              └─[왜 이 날짜인가요?]──▶ S3 근거 ★
        │
        └──[날짜 롱프레스]──────────────────────────────────▶ S3 근거 (바로)
```

> **⚠ 위젯이 주 소비처다.** 이 앱은 「앱을 여는 횟수」가 적다 — 위젯 3종의 디자인 비중이 높다.

### 1-C. 일정 등록 플로우

```
   S1 [＋]  또는  S2 [＋ 일정 추가]
        │
        ▼
   S4 일정 편집
        ├─ 날짜 [양력 ●] [음력 ○]   ← 탭 전환 시 반대편 값 즉시 미리보기
        ├─ 반복 [안 함 ▾]
        │    └ 음력 매년 + 윤달 날짜일 때만 → 윤달 정책 선택 (C-28)
        │         · 항상 평달 (기본)  · 윤달 우선  · 둘 다
        ├─ 알림 ☑당일 ☑1일 전 ☐3일 전 ☑7일 전 ☐14일 전
        └─ 색상 · 메모
```

### 1-D. 기일·생신 플로우 (A층의 핵심 동선)

```
   S5 기일·생신 목록
        │
        ├─ 아버님  기일 음력 10월 7일   다음 11/14(목)  D-99
        ├─ 어머님  생신 음력 3월 3일    다음 04/19(일)  D-14  만 71세 · 토끼띠
        │
        └─[＋ 사람 추가]  ※ 개수 제한 없음 (C-38)
```

### 1-E. 데이터 안전 플로우

```
   [모든 저장] ──▶ (자동) 백업 ──▶ 역파싱 검증
                                      │
                     ┌────────────────┼────────────────┐
                     ▼                ▼                ▼
                 ✅ 일치          ⏳ 검증 대기       ❌ 불일치
              홈 상단 배지        중립 회색         붉은 배너
        "백업 OK · 일정 128 ·                    + 차이 항목
         08-07 18:20"                            + [재시도]
```

> 백업 엔진은 **공수장부에서 전량 상속**한다(C-51). 배지·배너 규칙이 동일하므로 **같은 컴포넌트를 쓴다**(→ §5-5).

### 1-F. 전체 화면 지도 (IA)

```
S1 홈 · 월 달력  ★진입점
 ├─ [◀][▶] · 좌우 스와이프  → 월 이동
 ├─ [오늘]                  → 오늘로 복귀
 ├─ [검색]                  → S7 검색 (영구 무료)

                                ├─ 표시 항목 8종 토글
                                ├─ 글자 크기 3단계 · 테마 · 주 시작 요일
                                ├─ 알림 기본 시각 · 제사 전날 표시
                                ├─ 공휴일 데이터 상태
                                ├─ 기일·생신 목록      → S5

## 3. 공통 규칙 — **디자이너가 임의로 바꾸면 안 되는 것**

> 전부 실측된 사용자 불만이나 데이터 정확성에 직결된다.
> **여기 없는 것은 전부 재량이다.**

### 3-1. 날짜 표기 ★가장 중요

| 대상 | 규칙 | 올바른 예 | 금지 |
|---|---|---|---|
| **셀 음력** | `음 M.D` — **괄호로 감싸지 않는다** (C-4) | `음 8.15` | ❌ `(8.15)` ❌ `음력 8월 15일` |
| **셀 윤달** | 앞에 `윤` (C-4) | `윤 4.8` | ❌ `윤4월 8일` |
| **상세 음력** | `음력 M월 D일 (대/소)` (C-4, C-19) | `음력 8월 15일 (대)` | — |
| **양력** | 그레고리력만 | `2026년 3월 15일 (일)` | — |
| **간지** | 한자 + 한글 병기 | `庚辰(경진)` | ❌ 한자만 |
| **절입 시각** | `절입 06-21 23:57경(계산)` — **「경」과 「(계산)」 필수** (C-10) | | ❌ `06-21 23:57` (단정 표기) |
| **절입 시각 (자정 ±30분)** | **시각을 아예 표시하지 않고 날짜만** (C-10) | `절입 06-21` | ❌ 시각 표시 |
| **D-day** | `D-99` / `D-14` / `D-DAY` | | — |

> **왜 「경(계산)」이 붙는가**: 음력·절기의 **날짜**는 국가 확정값이지만 **절입 시각(분)**은 계산 추정치다.
> 틀린 시각을 단정적으로 보여주는 순간 이 앱의 유일한 소구점이 무너진다. **이 표기를 지워선 안 된다.**

### 3-2. 달력 격자 규칙

| # | 규칙 | 근거 |
|---|---|---|
| **G1** | **6주 고정 높이.** 앞뒤 달 날짜는 흐린 회색으로 채우되 **탭 불가** | C-7 — *"마지막 주가 안 보임"* 렌더링 불만 **32건**의 원인이 가변 높이 격자다 |
| **G2** | **주 시작 = 일요일** (설정에서 월요일 전환) | C-6 — 한국 종이 달력 관행 |

### S1. 홈 · 월 달력 ✅ ★진입점

**목적 — 3초 안에 답해야 하는 질문**
> **"오늘이 음력 며칠이고, 이번 달에 챙길 날이 언제인가?"**

**구성 요소 (위 → 아래)**

| 순서 | 요소 | 비고 |
|---|---|---|
| 1 | **월 네비게이션** `[◀] 2026년 3월 [▶]` + `[오늘] [검색] [＋]` | **헤더는 어떤 배율에서도 말줄임 금지** (C-8) |
| 2 | **백업 상태 배지** | `백업 OK · 일정 128 · 08-07 18:20` |
| 3 | **요일 헤더** (일~토, 주 시작 설정 반영) | 일=빨강 / 토=파랑 |
| 4 | **달력 격자 — 6주 고정** | 앞뒤 달은 흐린 회색, 탭 불가 (C-7) |
| 5 | **이달의 특일 한 줄** (가로 스크롤) | `3/1 삼일절 · 3/5 경칩 · 3/20 춘분` |
| 6 | **배너 광고** | 높이 예약, 실패 시 접힘 (C-50) |

**셀 내부 구성**
```
┌──────────────────┐
│ 15        음 6.2 │  ← 양력 ≥18sp (크게) / 음력 ≥12sp (작게, 우상단)
│                  │
│      초복        │  ← 특일 배지 (최대 2개, C-31)
│ ▌아버님 기일      │  ← 일정 = 배경 톤 + 좌측 색띠 (C-32)
└──────────────────┘
```

**표시 규칙**
- **양력 숫자가 셀에서 가장 크고 진하다.** 음력은 보조.
- 배지 최대 2개(음력 1 + 특일 1). 우선순위 `공휴일 > 잡절 > 절기 > 기념일 > 손없는날`
- 일정은 **점이 아니라 배경 톤 + 좌측 색띠**
- 연속 일정은 **가로 막대**, 주 경계에서 잘라 이어 그린다
- 오늘 = **굵은 테두리 + 배경**

**인터랙션**
- 날짜 **탭** → S2 날짜 상세 시트
- 날짜 **롱프레스** → **S3 근거 화면 (바로)**
- **좌우 스와이프** → 월 이동
- `[오늘]` → 오늘로 복귀
- 배지 탭 → S9 백업

**디자인 유의점**
- **셀에 최대 4개 정보**(양력·음력·배지·일정)가 들어간다. **배율 1.5 × 시스템 200%에서도 안 겹쳐야** 한다.
  → 배율이 올라갈 때 **무엇을 먼저 숨길지 규칙**을 제안해달라(권장: 음력 → 배지 순으로 유지, 일정 색띠는 끝까지).
- 표시 항목 8종 토글에 따라 **셀 내용이 크게 달라진다.** 전부 켠 상태 / 전부 끈 상태 둘 다 시안이 필요하다.
- 6주 고정이라 **아래쪽 여백이 생기는 달**이 있다. 그 여백을 어떻게 다룰지가 이 화면의 미감을 가른다.

### S2. 날짜 상세 시트 ✅ (바텀시트)

**목적**
> **"이 날이 무슨 날이고, 내 일정이 뭐가 있나"**

**구성**
```
2026년 3월 15일 (일)                    [＋ 일정 추가]
음력 1월 27일 (소) · 丙午월 庚辰일 · 손없는날 아님

■ 특일    없음
■ 일정    ▌아버님 기일 (음력 1월 27일) · 매년        [수정]
          ▌계모임 19:00~21:00                       [수정]

[왜 이 날짜인가요?]  → S3
```

**표시 규칙**
- 2행(음력·간지·손없는날)은 **토글 설정에 따라 항목이 사라진다** — 간지·손없는날은 기본 OFF
- 음력 일정은 **원래 음력 날짜를 괄호로 병기** (`아버님 기일 (음력 1월 27일)`)
- **광고 없음** (AD-7)

**디자인 유의점**
- **`[왜 이 날짜인가요?]` 버튼이 이 시트의 핵심 CTA다.** 눈에 띄어야 한다.
- 특일이 없는 날이 대부분이다 — **빈 상태가 초라해 보이면 안 된다.**

### S3. 근거 화면 ✅ ★★이 앱의 심장

**목적**
> **"왜 이 날짜인지 납득시킨다"**

**구성**
```
2026년 7월 15일 (수)
음력 6월 2일 (소)  ·  일진 庚辰(경진)

■ 초복
  하지 당일부터 세어 세 번째 庚(경)일입니다.

  하지 2026-06-21(庚일)  →  ① 06-21   ② 07-05   ③ 07-15
                                              ↑ 오늘

  ※ 하지 당일이 庚일이면 그날을 첫 번째로 셉니다.

■ 이 날짜의 출처
  음력·24절기 : 한국천문연구원 확정값 (1900~2050)
  잡절·간지    : 위 확정값으로 계산
  데이터 확인  : 2026-08-07
```

**표시 규칙**
- **계산 과정을 단계로 보여준다** — `①②③` 진행이 시각적으로 읽혀야 한다
- **결론 날짜를 강조**한다 (위 예에서 `③ 07-15`)
- 절입 시각은 **C-10** 준수 — `경(계산)` 표기, 자정 ±30분이면 시각 미표시
- **출처 블록(L3)은 필수**이며 지울 수 없다
- **광고 없음** (AD-7)

**근거 화면을 갖는 대상 (전부)**
간지 · 잡절(삼복·한식) · 24절기 · 대체공휴일 · 윤달 · 설/추석 연휴

**디자인 유의점**
- **이 화면이 다른 달력 앱에는 없다.** 이 앱을 사는 이유이고, 스크린샷 1순위다.
- *"24년 2월 5일이 갑진년이라니 못 믿겠다"* 같은 리뷰가 **이 화면 하나로 끝난다.** 논쟁을 종결시키는 톤이어야 한다 — 방어적이지 않고, 담담하게 증명하는.
- 계산 단계가 **4~5단까지 길어지는 경우**(대체공휴일 연쇄)가 있다. 그때도 무너지지 않아야 한다.
- **공유 버튼**을 검토해달라 — 가족 단톡방에 "이게 근거야"로 보내는 동선이 자연스럽다(명세엔 없으나 제안 환영).

      └ 음력 매년 + 윤달 날짜일 때만 → 윤달 정책 선택 (C-28)

알림  ☑당일 ☑1일 전 ☐3일 전 ☑7일 전 ☐14일 전    시각 [09:00]

색상  ● ● ● ● ● ●

메모  [                          ]
```

**표시 규칙**
- **양력↔음력 탭 전환 시 반대편 값이 즉시 미리보기**된다 — 이게 이 화면의 핵심 UX
- **윤달 정책 선택은 윤달 날짜에 등록할 때만** 뜬다. 평달 등록 시엔 묻지 않는다 (C-28 — A층 피로 방지)
  - `항상 평달`(기본) / `윤달 우선` / `둘 다`
- 알림 기본 프로필: **기일·생신 = D-7, D-1, 당일** / 일반 일정 = 당일 (C-34)
- 알림 시각 기본 **09:00** (사용자 설정값, 「8시 고정」은 실측 불만)

**디자인 유의점**
- **윤달 정책 다이얼로그가 어렵다.** 40~70대에게 "윤달 우선"이 무슨 뜻인지 그림으로 설명해야 한다.
  → 예시 날짜를 함께 보여주는 방식을 제안해달라.
- 반복 6종 + 알림 5단 + 색상이 한 화면에 있다. **스크롤 없이 저장 버튼이 보이긴 어렵다** — 단계 분할을 검토해도 좋다.
