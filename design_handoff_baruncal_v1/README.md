# 핸드오프: 바른달력 v1.0 — 모바일 앱 UI

작성 2026-08-10 · 대상: 구현 팀 (Android 우선, Play 배포)
원본 요구사항: `원본-의뢰서.md` (2026-08-09 · 규칙 ID C-1~C-52는 이 문서 전체에서 그대로 인용한다)

---

## 1. 개요

바른달력은 **음력·24절기·잡절·간지·공휴일을 정확하게 보여주고, "왜 이 날짜인가"를 계산 과정으로 증명하는** 한국형 달력 앱이다. 경쟁 앱들이 죽은 자리는 대부분 정확성이 아니라 **정확성을 설명하지 못한 것**이었고(C-11, C-30), 그래서 이 앱의 차별점은 S3 근거 화면 하나에 집중되어 있다.

핵심 제품 원칙 4가지:

1. **추정치를 절대 표시하지 않는다.** 한국천문연구원 확정값 범위(1900~2050) 밖은 계산해서 보여주는 대신 명시적으로 거절한다 (C-20, E5).
2. **조용히 실패하지 않는다.** 백업 불일치, 정확 알람 권한 거부, 광고 로드 실패 모두 사용자에게 보이는 상태를 갖는다 (C-35, C-50).
3. **개수 제한을 과금 수단으로 쓰지 않는다.** 달력·음력·절기·간지·공휴일·검색·위젯·백업·기일 무제한은 영구 무료. 유료는 광고 제거·큰 글씨·다단 사전 알림·다크/위젯 테마 4가지뿐 (C-48, C-49).
4. **색만으로 정보를 전달하지 않는다.** 공휴일은 빨강 + 상세에 이름, 일정은 배경 톤 + 좌측 색띠 (A3).

## 2. 이 번들의 디자인 파일에 대하여

`바른달력 목업.dc.html`은 **HTML로 만든 디자인 레퍼런스**다. 의도한 외형과 동작을 보여주는 프로토타입이며, **그대로 가져다 쓰는 프로덕션 코드가 아니다.**

해야 할 일은 이 HTML 디자인을 **대상 코드베이스의 기존 환경에서 다시 만드는 것**이다 — Android(Compose/View), React Native, Flutter 등 프로젝트가 이미 쓰는 프레임워크와 확립된 패턴·라이브러리를 따른다. 아직 환경이 없다면 프로젝트에 가장 적합한 프레임워크를 선택해 구현한다.

목업 안의 음력·간지·절기 계산 로직 역시 **표시 규칙을 증명하기 위한 참조 구현**이다. 실제 앱은 KASI 확정 데이터(1900~2050)를 내장해야 하며, 목업은 2025-01~2028-01 범위의 삭일 테이블만 가지고 있다.

### 목업 열어보는 법

`바른달력 목업.dc.html`을 브라우저에서 직접 연다(같은 폴더의 `support.js` 필요). 상단 툴바로 전환 가능한 것:

- **보기**: 단일(인터랙티브) / 나란히(14개 프레임 동시 비교)
- **화면**: S1 홈 · S3 근거 · S4 편집 · S5 기일 · S6 변환 · S7 검색 · S8 설정 · S9 백업 · S10 가져오기 · S11 페이월 · W 위젯
- **배율**: 1.0 / 1.25 / 1.5 (C-8 검증용)
- **테마**: 라이트 / 다크
- **표시항목**: 전부 켬 / 기본 / 전부 끔 (8종 토글, C-31 절삭 검증용)
- **상태**: 백업 OK / 검증 대기 / 불일치 (X1)
- **예외**: 범위 밖 E5

인터랙션: 날짜 **탭** → S2 시트, 날짜 **롱프레스(데스크톱은 우클릭)** → S3 근거 직행, `◀ ▶` → 월 이동, 백업 배지 탭 → S9.

**기준 날짜는 2026-07-15(수)** 로 고정되어 있다. 이 날은 초복이며, 목업의 D-day·「오늘」 표시는 모두 이 날짜 기준이다.

## 3. 완성도(Fidelity)

**하이파이(hifi)** 다. 색·타이포·간격·인터랙션이 최종안이다. 아래 §9 디자인 토큰의 값을 그대로 쓰고, 레이아웃도 픽셀 단위로 재현한다.

단, 다음은 의도적으로 미완이며 구현 팀 재량이다:

- 아이콘 — 목업은 텍스트 글리프(`◀ ▶ ☰ ＋ ✓ ›`)로 대체했다. 실제로는 시스템 아이콘 세트를 쓴다.
- 스와이프 제스처 — 목업은 `◀ ▶` 버튼만 구현. 실제로는 좌우 스와이프 월 이동이 필수다.
- 폰트 — 목업은 Noto Sans KR / Noto Serif KR. 안드로이드에서는 시스템 기본(Roboto + Noto Sans KR 폴백)으로 대체 가능하나, **손글씨체·장식체는 금지**한다.

## 4. 화면 명세

기준 뷰포트 **390×812**. 지원 범위 360~480px 폭. 아래 px 값은 배율 1.0 기준이며, 배율 계수 `s`가 곱해지는 값은 `× s`로 표기한다.

### 공통 구조

```
┌─────────────────────────────┐
│ 상태바 (30px, 시스템)         │
├─────────────────────────────┤
│ 헤더 (S1 제외 전 화면)         │  ← ← 버튼 44×44 + 제목 18px×s / 700
│   하단 border 1px line       │
├─────────────────────────────┤
│ 스크롤 영역 (flex:1)          │
└─────────────────────────────┘
```

바텀 탭바는 **없다.** 의뢰서 §5 화면 지도에 존재하지 않으며, 홈 하단 1지면은 광고(AD-6)가 점유한다. 모든 이동은 홈 상단 액션 4개(`오늘 / 검색 / ☰ / ＋`)와 설정 리스트를 통한다.

### S1. 홈 · 월 달력 ★진입점

**목적** — 3초 안에 "오늘이 며칠이고 음력 며칠이며 특별한 날인가"에 답한다.

**레이아웃 (위에서 아래로)**

| # | 요소 | 사양 |
|---|---|---|
| 1 | 월 네비게이션 | `◀`(44×48) + 중앙 제목 + `▶`(44×48). 제목 `2026년 7월` **22px×s / 700 / tnum / line-height 1.2 / 말줄임 절대 금지** (C-8). 2줄 허용 |
| 2 | 액션 행 | `[오늘] [검색]` 좌측 · spacer · `[☰] [＋]` 우측. 높이 36px, radius 9px, gap 6px. 오늘/검색/☰는 outline(1px line, surface 배경), ＋는 accent 채움 |
| 3 | 백업 상태 배지 | full-width, min-height 44px, padding 9/12, radius 10px, 13px×s, tnum. 3상태 — §5 X1 참조. 탭 → S9 |
| 4 | 요일 헤더 | 7열 grid, padding 7px 0, 13px×s / 700, 중앙정렬. 일=red, 토=blue, 그 외 ink2 |
| 5 | **달력 격자 — 6주 고정** | 7×6 = 42셀. 상단 1px line border-top |
| 6 | 이달의 특일 한 줄 | 가로 스크롤, gap 14px, padding 12px 2px 4px, 14px×s. 공휴일은 red/700, 나머지 ink2/400 |
| 7 | 페이월 사전 고지 (L1 · C-49 필수) | 12px×s / ink3 / 중앙 / line-height 1.5. 문구 고정: `모든 달력 기능 무료 · 구독 없음 · 광고 제거는 1회 결제 ₩7,900` |
| 8 | 배너 광고 | 높이 **64px 사전 예약**, margin 0 10px 12px, 1px dashed line, radius 10px. 로드 실패 시 접힘 (AD-5, C-50) |

**셀 사양 (G1~G5, C-31)**

```
min-height: 58px × s
padding: 5px 4px 4px
border-right / border-bottom: 1px solid line
display: flex; flex-direction: column; gap: 2px
overflow: hidden
```

셀 내부 순서 (위 → 아래):

1. **양력 숫자** — 19px×s, 오늘이면 700 아니면 500, tnum, line-height 1.1, 좌측 정렬
2. **음력** — 12px×s, ink3, tnum, line-height 1.2, **우측 정렬**, 형식 `음 6.2` / 윤달은 `윤 6.2`
3. **특일 배지 (최대 1개)** — 11px×s, line-height 1.25, 1줄 말줄임. 공휴일 red/700, 잡절 accent/500, 그 외 ink2/500
4. **일정 색띠 (최대 2개)** — 10.5px×s, padding 1px 3px 1px 5px, **좌측 3px solid 일정색**, 배경 `일정색 + 12% alpha`(hex 접미 `1f`), 1줄 말줄임

셀 배경:
- 오늘 → `--todayBg` + `box-shadow: inset 0 0 0 2px accent`
- 일정 있는 당월 날 → `--surface2`
- 그 외 → transparent
- **앞뒤 달 → opacity 0.55, ink3, 탭 불가** (C-7)

숫자 색 우선순위: 앞뒤달(ink3) > 일요일 또는 공휴일(red) > 토요일(blue) > 기본(ink)

**셀 정보 절삭 규칙 (C-31)** — 배지는 최대 2개(음력 1 + 특일 1). 특일이 여럿이면 **공휴일 > 잡절 > 절기 > 기념일 > 손없는날** 순으로 하나만 남긴다. 배율이 올라가면 **음력 → 특일 배지 순으로 숨기고, 일정 색띠는 끝까지 유지**한다. 목업 구현: 배율 ≥ 1.5이고 특일이 있으면 음력을 숨기고, 색띠는 2개 → 1개로 줄인다.

**인터랙션**

- 날짜 **탭** → S2 바텀시트 (당월 날짜만)
- 날짜 **롱프레스** → S3 근거 직행
- **좌우 스와이프** → 월 이동 (필수 구현)
- `[오늘]` → 2026-07로 복귀 + 오늘 선택
- 배지 탭 → S9
- 범위(1900~2050) 밖으로 이동 시도 → 격자 대신 **E5 블록** 표시 (§5 참조)

### S3. 근거 화면 ★ — 이 앱의 차별점

**목적** — "왜 오늘이 초복인가"를 **계산 단계로 증명**한다. 경쟁 앱 어디에도 없는 화면이고, 리뷰 불만 C-11·C-30이 정확히 이 자리다.

**레이아웃**

```
padding: 14px 16px 30px

[날짜]        2026년 7월 15일 (수)     21px×s / 700 / tnum
[부제]        음력 6월 2일 (대) · 일진 庚辰(경진)
              15px×s / ink2 / Serif / lh 1.6

━━ [4px accent 막대] 초복        19px×s / 700   ← 섹션 헤더, 하단 1px line
   하지가 지난 뒤 세 번째 庚(경)일입니다.
   16px×s / ink / lh 1.75

┌ 계산 카드 (1px line, radius 14px, surface, padding 14px) ┐
│ 하지 2026-06-21 (절입 06-21 · 자정 근처라 시각 미표시)      │  14px×s / ink2 / tnum
│                                                          │
│ ① 06-25  丙午 …아니고 庚…      ← 단계 행, gap 8px         │
│ ② 07-05  庚戌                                            │
│ ③ 07-15  庚辰            ← 이 날   (accent / 700)        │
│ ─────────── 1px dashed ───────────                       │
│ ※ 하지 당일이 庚일이면 그날을 첫 번째로 셉니다.              │  13px×s / ink2
└──────────────────────────────────────────────────────────┘

━━ 이 날짜의 출처                16px×s / 700   ← L3 필수
   음력·24절기   한국천문연구원 확정값 (1900~2050)
   잡절·간지     위 확정값으로 계산
   데이터 확인   2026-08-07
   13px×s, 라벨 열 폭 84px×s / ink3

[근거 공유]  [닫기]      높이 50px, radius 11px, 1:1
```

**단계 행 사양** — 번호(①②③④) + 날짜(`07-15`, tnum) + 주석(13px×s / ink2 / **Serif**) + spacer + `← 이 날`(accent/700). 해당 행은 배경 accentSoft + radius 8px로 강조.

**근거 유형별 내용** (목업에 전부 구현되어 있음)

| 유형 | 규칙 문구 | 기준점 | 단계 |
|---|---|---|---|
| 초복 | 하지가 지난 뒤 **세 번째** 庚일 | 하지 2026-06-21 | ① 06-25 ② 07-05 ③ 07-15 |
| 중복 | 하지가 지난 뒤 **네 번째** 庚일 | 하지 2026-06-21 | ① 06-25 … ④ 07-25 |
| 말복 | 입추가 지난 뒤 **첫** 庚일 | 입추 2026-08-07 21:19경(계산) | ① 08-04 (입추 전이라 세지 않음) ② 08-14 |
| 대체공휴일 | 본 공휴일이 주말과 겹쳐 다음 첫 비공휴일로 이동 | 광복절 2026-08-15(토) | ① 08-15 토 ② 08-16 일 ③ 08-17 월 → 대체 |
| 24절기 | 태양 황경이 정해진 각도에 이르는 순간이 든 날 | 절입 시각 | ① 입절 ② 월건 전환 |
| 일진(기본) | 60간지를 하루에 하나씩 순서대로 | 월건 + 음력일 | 전날·당일·다음날 3행 |

> **의뢰서 §7 예시값 정정** — 의뢰서의 초복 단계 `①06-21`은 10일 간격에 맞지 않는다. 2026년 하지(06-21)는 **丙**일이므로 세지 않고, 첫 庚일은 06-25다. 말복은 중복과 20일 간격이라 **월복(越伏)** 이며 이 사실을 주석에 표시한다.

**시각 표기 규칙 (C-10)** — 절입 시각은 `21:19경(계산)`처럼 **「경(계산)」을 반드시 붙인다**. 자정 ±30분에 드는 절입(2026 하지 등)은 **시각을 아예 표시하지 않는다** — 날짜 경계 오해를 막기 위해서다.

**`근거 공유`** — 근거 요약 텍스트를 클립보드에 복사하고 `근거 요약을 복사했습니다 — 가족 단톡방에 붙여넣을 수 있습니다` 안내를 띄운다. 이게 이 앱의 유일한 바이럴 경로다.

## 10. 앱 아이콘

## 11. 인터랙션 · 모션

목업의 **인터랙션** 화면(스크린샷 14)에서 전부 실제로 눌러볼 수 있다.

| 대상 | 사양 |
|---|---|
| 누름 피드백 | `scale(0.96)` · 120ms · ease. 주 버튼은 밝기 0.88배, 보조 버튼은 배경 accentSoft. 손을 떼면 즉시 복귀 |
| 셀 탭 | 리플 420ms ease-out (중심에서 확산, opacity 0.5 → 0) 후 시트 열림 |
| 셀 롱프레스 | 500ms · 진동 짧게 1회 → 근거 화면 직행. 앞뒤 달 셀은 두 제스처 모두 무반응 |
| 바텀시트 열림 | `translateY(100% → 0)` · 260ms · `cubic-bezier(0.05,0.7,0.1,1)` · 배경 딤 동시 페이드 |
| 월 이동 | shared axis X · 220ms. 다음 달은 우→좌, 이전 달은 좌→우. 헤더 숫자도 함께 이동 |
| 화면 진입 | 페이드 180ms + 12px 상승. 뒤로가기는 역방향 |
| 안내 메시지 | 14px 상승 + 페이드 160ms → 2.2초 유지 → 페이드 아웃 160ms |
| 토글 | 노브 transform 180ms `cubic-bezier(0.2,0,0,1)`, 트랙 배경색 동일 타이밍 |
| 스켈레톤 | 1.2s linear 무한 · 220px 폭 그라디언트 스윕 · 항목마다 0.15s 지연 |

**스켈레톤은 백업 검증·가져오기 미리보기에만 쓴다.** 달력 격자는 내장 데이터라 즉시 그려지므로 로딩 표시를 넣지 않는다.

**진동(햅틱)**

| 상황 | 패턴 |
|---|---|
| 날짜 롱프레스 | 짧게 1회 (근거 화면 진입 직전) |
| 저장 · 가져오기 완료 | 짧게 1회 |
| 백업 불일치 · 삭제 확인 | 두 번 (경고 패턴) |
| 그 외 탭 | 진동 없음 — 달력을 넘기는 동작에 진동을 붙이지 않는다 |

**모션 줄이기 설정이 켜져 있으면** 모든 이동·확대 전환을 120ms 페이드로 대체하고, 리플과 스켈레톤 흐름은 끄고, 누름 피드백은 색 변화만 남긴다.

## 14. 구현 시 주의할 점

1. **S3 근거 화면이 이 앱의 전부다.** 다른 화면을 줄여서라도 이 화면의 정확성과 읽기 쉬움을 지킨다.
2. **의뢰서 §7의 예시값 일부는 실제 계산과 어긋난다.** 초복 단계는 `하지 06-21(丙) → ① 06-25 ② 07-05 ③ 07-15`가 맞다. 하지 절입은 자정 근처라 C-10에 따라 시각을 표시하지 않는다. 목업은 계산값을 따랐다. **구현 시 KASI 확정 데이터로 다시 검증할 것.**
3. **월건은 절기 입절 기준으로 바뀐다.** 음력 초하루가 아니다. 흔한 버그 자리다.
4. **셀 절삭 규칙(C-31)을 배율 1.5 · 시스템 폰트 200%에서 반드시 테스트한다.** 목업의 「나란히」 보기에 배율 1.5 프레임과 표시항목 전부 켬/끔 프레임이 들어 있다.
5. **6주 달 테스트 케이스**: 2026년 8월(토요일 시작). **윤달 케이스**: 2025년 윤 6월. **배지 초과 케이스**: 공휴일 + 절기 + 손없는날 동시.
6. **광고는 홈 하단 1지면뿐이다.** 상세 시트·근거·편집·설정·백업·변환기·검색·위젯에는 절대 넣지 않는다 (AD-7). 등급 G + 성인·데이팅·선정성·가짜 시스템 경고·자동 설치 유도·저가 커머스 카테고리 차단 (AD-4).
7. **온보딩 화면을 만들지 않는다.** 앱을 열면 바로 달력이다. 대신 홈 하단 L1 고지 1줄이 그 역할을 한다 (C-49).
